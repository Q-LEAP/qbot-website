Interface & API

Pilotez Q-BOT comme vous voulez

Q-BOT offre deux modes d'utilisation complémentaires pour s'adapter à tous les workflows de test.

Interface Web Créez vos scénarios d'authentification via une interface intuitive, accessible depuis n'importe quel navigateur sur votre réseau.
API REST Déclenchez Q-BOT directement depuis vos scripts de test : Selenium, Cypress, Appium, Playwright, Robot Framework et bien d'autres.
Notification mobile Déclenchez manuellement via notification mobile pour les cas de test semi-automatisés.
Confidentialité

Zéro rétention de données

Q-BOT est conçu pour respecter la confidentialité et la sécurité de vos données de test.

Photos supprimées

Les captures d'écran sont immédiatement supprimées après extraction du code OTP. Aucune image n'est conservée.

Données de test uniquement

Q-BOT doit être utilisé avec des données de test, non de production. Les scénarios créés restent sur l'appareil.

Réseau local

Q-BOT fonctionne sur votre réseau interne. La communication entre Q-BOT et vos outils de test reste locale.

Surveillance incluse

En cas de dysfonctionnement, le support Q-Leap peut intervenir à distance. Si non résolvable, remplacement du robot.

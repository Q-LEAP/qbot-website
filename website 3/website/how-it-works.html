End-to-End Flow

From test scenario
to automated 2FA.

Q-Bot removes the human bottleneck from 2FA without asking your team to write scripts, configure device farms, or manage cloud services. Here is exactly what happens.

1
Build your scenario — no scripting

Open the Q-Bot web interface and create a new scenario. Upload a screenshot of the 2FA app screen you want to automate — the approval screen, the OTP screen, whatever the step requires.

Place numbered tap points directly on the screenshot in the order they should be executed. Set a wait time between taps if the app needs a moment to respond. That's your scenario — a visual map of where Q-Bot should tap and when.

Upload screenshot Place tap points Set wait times Save scenario
2
Connect your Android device

Q-Bot connects to a real Android device over USB. The device runs your actual 2FA app — a banking authenticator, LuxTrust, an enterprise SSO app, or any app that lives on a phone.

ADB (Android Debug Bridge) handles the communication between Q-Bot's hardware and the device, executing taps and swipes exactly as a human finger would. Because it operates the real app on real hardware, Q-Bot replicates production behaviour faithfully — no emulators, no mocked responses.

3
Trigger a scenario — two paths

When your automated test reaches the 2FA step, Q-Bot takes over. There are two ways to trigger execution:

Path A — REST API
For CI/CD and test frameworks

Your test framework sends a single HTTP request. Q-Bot looks up the scenario and immediately begins replaying it on the connected device. Explicit, deterministic, easy to integrate into any pipeline.

GET /scenarios/:id/execute
Path B — Companion App
Automatic BLE trigger

The Q-Bot companion app uses Android's Accessibility Service to monitor 2FA notifications. When one is detected, it notifies Q-Bot over Bluetooth — no call from your test runner needed.

Fires automatically on notification

Both paths can coexist — use whichever fits your test flow, or use both in different scenarios.

4
2FA completes. Test continues.

Q-Bot replays the scenario on the Android device — tapping the approval button, entering the OTP, navigating the flow — whatever the scenario defines. The 2FA step resolves. Control returns to your test. The pipeline moves forward.

No human intervention. No waiting. No wasted time.

Additional capabilities

Beyond scenario execution, two more APIs are available on port 8000.

LuxTrust OTP Retrieval

Read the one-time password currently displayed by the LuxTrust app on the connected device — useful for test assertions or form submissions in flows that require the raw OTP value.

GET /get-luxtrust-otp
QR Code Display for 2FA

Push a QR code fullscreen to Q-Bot's small attached screen. A scenario then instructs the Android device to open its camera and scan the code — automating QR-based 2FA flows end to end.

POST /display-image

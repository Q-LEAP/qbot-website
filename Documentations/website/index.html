Your pipeline is automated. Except for this.

You've invested in test automation. Your regression suite runs overnight. Your CI/CD pipeline is finely tuned.

Then a 2FA prompt appears.

Someone has to pick up a phone, approve a push notification, or read a one-time code — at 2am, on a weekend, every sprint. That single manual step costs hours, blocks pipelines, and turns "fully automated" into a polite fiction.

Q-Bot fixes that.

Built for teams who automate everything

Q-Bot is purpose-built for one job: making 2FA a non-event in your automated test suite.

No human in the loop

Q-Bot handles 2FA automatically — every time, on demand, at any hour — without a tester standing by.

Real device. Real fidelity.

Q-Bot operates a genuine Android device via ADB — LuxTrust, Microsoft Authenticator, Google Authenticator, itsme, or any other 2FA app. Not a simulator, not a stub — the actual app on real hardware.

Zero scripting

Build automation scenarios visually: upload a screenshot, tap where actions should happen. No code, no maintenance overhead.

Drops into any pipeline

One REST API call triggers a scenario. Selenium, Cypress, Robot Framework, a shell script — if it makes HTTP requests, it works with Q-Bot.

How it works

From scenario creation to automated 2FA in four steps.

01 — Build
Upload screenshots, place tap points, set wait times — no scripting required.
02 — Trigger
Via REST API from your test runner, or automatically the instant the companion app detects a 2FA notification.
03 — Execute
Q-Bot replays the scenario on the connected Android device — taps, swipes, and waits — via ADB.
04 — Continue
2FA handled. Pipeline unblocked. Test continues from exactly where it left off.

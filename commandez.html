Fonctionnement

Comment Q-Bot automatise votre 2FA ?

Un processus entièrement automatisé, en moins de 10 secondes.

1

Déclenchement

Votre script de test appelle l'API Q-Bot. L'actionneur appuie sur le bouton du dispositif 2FA (LuxTrust, smartphone, etc.).

2

Capture & analyse

La caméra HD capture l'écran illuminé du dispositif. La vision par ordinateur extrait le code OTP en temps réel.

3

Retour API

Le code OTP est renvoyé à votre script en moins de 10 secondes. Il est saisi automatiquement dans votre application.

4

Sécurité

La photo est supprimée immédiatement après traitement. Aucune donnée n'est conservée en dehors de Q-Bot.

Interface & API

Control Q-BOT however you want

Q-BOT offers two complementary usage modes to fit any test workflow.

Web interface Create your authentication scenarios through an intuitive interface, accessible from any browser on your network.
REST API Trigger Q-BOT directly from your test scripts: Selenium, Cypress, Appium, Playwright, Robot Framework and many others.
Mobile notification Trigger manually via mobile notification for semi-automated test cases.
Privacy

Zero data retention

Q-BOT is designed to respect the privacy and security of your test data.

Photos deleted

Screenshots are immediately deleted after OTP code extraction. No image is retained.

Test data only

Q-BOT must be used with test data, not production data. Scenarios created remain on the device.

Local network

Q-BOT runs on your internal network. Communication between Q-BOT and your test tools stays local.

Monitoring included

In case of malfunction, Q-Leap support can intervene remotely. If unresolvable, the robot is replaced.

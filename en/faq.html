The main questions about Q-BOT

Discover answers to your main questions about Q-BOT, an innovation by Q-Leap enabling two-factor authentication via a mobile app.

Q-BOT is a one-of-a-kind robot designed to automate two-factor authentication (2FA) via mobile applications or secure devices. It enables the automation of testing processes that were previously inaccessible.

Q-BOT enables automation of critical test cases requiring two-factor authentication: 2FA login, document signing, transaction validation, official requests. Without Q-BOT, these scenarios require human intervention, making full automation impossible.

Testers can cover all application features without any omissions. Q-BOT is simple (no software installation), fast (OTP in under 10 seconds), 100% effective (perfect recognition rate), and accessible via Web interface or API.

Book a meeting directly via our contact form or call +352 20 21 17. You can also email bot@q-leap.eu and ask for Sylvain Perez, who will organize a personalized demonstration.

Q-BOT is compatible with all types of smartphones for two-factor authentication. Originally designed for physical LuxTrust tokens (used in Luxembourg), Q-BOT now supports universal smartphone authentication: Google Authenticator, Microsoft Authenticator, and mobile 2FA apps.

After connecting to the network, create your scenarios via Q-BOT's Web interface. Triggering occurs either via mobile notification or API call from your automation tools: Selenium, Cypress, Appium, Playwright, Robot Framework, Jenkins CI, GitLab CI, etc.

Q-BOT only retains data related to the creation of authentication scenarios. Captured photos are deleted immediately after processing. It is recommended to use Q-BOT with test data only, not production data.
